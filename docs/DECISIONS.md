# Durable decisions

- Native scrolling is the single narrative scroll authority; ScrollTrigger reads its progress for camera movement. Inspection locks document scroll and restores position on exit. OrbitControls is active only during inspection.
- A persistent R3F canvas supports authored surface views and a reusable component inspector. Lightweight schematic geometry is a functional educational reconstruction, not an exact NASA model.
- Phase 1 has three hero discoveries. Future chapters remain configuration entries.
- Official NASA sources govern factual UI. The DOCX supplies narrative structure, not technical authority. Its reference to indefinitely intact footprints is softened: no wind or rain, but impact weathering occurs. Speculative future preservation is not asserted as fact.
- Future chapter fact-review flags: the Spirit introduction incorrectly repeats Sojourner; claims about intact rover hardware and tracks require verification; Opportunity's famous battery sentence must not be presented as a verbatim rover transmission. No such claims appear in Phase 1.
# Implementation notes

The Sites starter was inspected in .scaffold. Its Vinext/server and general UI catalog were not adopted: the user's explicit Vite/React/TypeScript, small-stack, static 3D-experience requirements govern this build. The unused temporary scaffold was removed after inspection and is not shipped. Hosting uses Sites static output with the single registered project ID.
