# Design system

The world is the primary surface. Ivory monospace annotations, condensed editorial headings, occasional quiet serif interpretations, thin rules, hard edges, and large negative space. No card grid or dashboard chrome.

Space: near black #05080c, cyan-gray #a6cfd1. Apollo: charcoal #090a0b, ivory #eee9dd, muted gold #d3b97f. CSS tokens live in src/styles.css; lighting is controlled in World.tsx. Future chapter palettes are in archive.ts.

Camera grammar: wide Moon globe, scroll approach, distant unidentified structure, closer site exploration, isolated component investigation. Orbit freedom is restricted to inspection. Text follows unknown evidence → identity → purpose → interpretation. Footprint reconstruction uses a real NASA archival photograph with an explicitly fictional recovery interaction.

Mobile retains the same learning gates. Model viewport becomes the upper part of the screen; inspection controls scroll beneath it. Native range inputs and buttons replace reliance on precise pointer gestures. All modals support Escape, focus containment and return. Reduced-motion mode retains every route through the narrative.
