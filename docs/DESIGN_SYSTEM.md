# Design system / playable world revision

Full-viewport exploration game. Actual NASA imagery and detailed textured 3D hardware dominate. Opening is flight-ready: one small objective, a controllable spacecraft, a large cropped Moon, a target, measured telemetry, and terse controls. No oversized slogan, card navigation, serif marketing headline, or ornamental paragraph in the flight path.

Colors: almost-black #020408, cold white #e9f0ed, cyan #9ae2e8 for input and targeting; physical hardware gold only. Flight information uses IBM Plex Mono. Barlow Condensed for large numbers, destination names, and only brief identification reveals. No decorative gradient panels or rounded card grid.

Keep >= two-thirds of the frame as world. Edge-aligned HUD, thin measured lines, restrained grain, high-contrast readable controls. Main labels >=12px desktop and 11px mobile; interaction labels >=14px. Touch targets >=40px. Important learning text >=16px.

Surface: real NASA lunar imagery supplies photographic regolith/horizon; Apollo descent stage is a credited NASA 3D reconstruction. Distant-future scene, alien ship, missing ascent stage selection, parts separation and floating interface are interpretive. No claim of exact survey coordinates or preservation state. Descent stage stays visually distinct from complete historical lander imagery.

Inspection is an in-world scan: lunar background stays visible; components move into stable separated positions; spatial labels connect to them. Selected component exposes concise purpose and metadata; no permanent right-side sidebar. Keyboard and mobile component controls expose the same content. Escape returns reliably; reduced-motion preserves every learning gate.

Flight has manual keyboard/touch controls, clear speed/target feedback, soft-failure/retry, and explicit assisted option. Mars uses real NASA imagery only as the ending teaser. Existing three-discovery progression and citations remain.
