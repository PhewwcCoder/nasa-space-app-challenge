# Design system / playable world revision

Current precedence: the 2026-09-27 section below supersedes the cockpit and default-assist rules in earlier revision notes.

Full-viewport exploration game. Actual NASA imagery and detailed textured 3D hardware dominate. Opening is flight-ready: one small objective, a controllable spacecraft, a large cropped Moon, a target, measured telemetry, and terse controls. No oversized slogan, card navigation, serif marketing headline, or ornamental paragraph in the flight path.

Colors: almost-black #020408, cold white #e9f0ed, cyan #9ae2e8 for input and targeting; physical hardware gold only. Flight information uses IBM Plex Mono. Barlow Condensed for large numbers, destination names, and only brief identification reveals. No decorative gradient panels or rounded card grid.

Keep >= two-thirds of the frame as world. Edge-aligned HUD, thin measured lines, restrained grain, high-contrast readable controls. Main labels >=12px desktop and 11px mobile; interaction labels >=14px. Touch targets >=40px. Important learning text >=16px.

Surface: real NASA lunar imagery supplies photographic regolith/horizon; Apollo descent stage is a credited NASA 3D reconstruction. Distant-future scene, alien ship, missing ascent stage selection, parts separation and floating interface are interpretive. No claim of exact survey coordinates or preservation state. Descent stage stays visually distinct from complete historical lander imagery.

Inspection is an in-world scan: lunar background stays visible; components move into stable separated positions; spatial labels connect to them. Selected component exposes concise purpose and metadata; a transparent right-side learning poster during selected hardware inspection. Keyboard and mobile component controls expose the same content. Escape returns reliably; reduced-motion preserves every learning gate.

Flight has manual keyboard/touch controls, clear speed/target feedback, soft-failure/retry, and explicit assisted option. Mars uses real NASA imagery only as the ending teaser. Existing six-discovery progression and citations remain.

## Third-person flight and field guide / 2026-09-27

Keep the existing minimalist opening typography, header and two low instrument displays. Remove first-person gloves from the active composition. Show the whole spacecraft against the terrain from high altitude; move closer during descent. Frame the landing ring above the instruments and ahead of the craft. Manual is the initial state; text must describe the current mode honestly.

Preserve gold/metal model materials. Use only faint emissive selection plus a thin low-opacity halo. Selection is reversible; checkmarks mean current selection, while progress is tracked separately. Learning panels use more transparent backgrounds and mild blur with readable white text. Replace clipped reference-poster crops with credited real NASA photos that unfold on hover, focus or tap. Mobile receives the same photo and learning content.

The Apollo field guide is a single native scrolling page with wide editorial photo/text pairs, section links and a two-column code/annotation view. On phones these become a single column with horizontally scrollable source lines. Topic buttons and line buttons have pressed states; all content is available without hover. Code is original text, explanations are authored summaries. The fixed dialog header always exposes exit.

Wrong quiz answers say they are incorrect before providing the right fact. Footprint evidence appears at normal exposure immediately. Faint, infrequent sky motion stays decorative, is identified as fictional, never captures input, and disappears for reduced motion.

## Student hardware revision / highest precedence
Right-edge flight telemetry uses large tabular numerals, small unit labels, a vertical measuring rule and warm descent accent. The map stays at the lower left. Preserve a clear central flight path. Dust should read as gray, low, flowing veils with soft irregular edges, never solid bubbles; the lunar effect represents disturbed regolith.

Use warm metallic gold/copper foil, silver panels and charcoal insulation for Eagle. Avoid flat yellow plastic and globally darkening the world. The walking explorer swings limbs with alternating steps. Scan entry is a scroll-scrubbed camera move with targeting graphics, an explicit Continue control and an immediate reduced-motion equivalent.

Hardware reading stays on the right of the visible model: warm white #fafbf8, ink #243c42, teal source links, 17px prose with 1.75 line height, Miso and a real credited photograph. Nine short sentences form two paragraphs, without numbered bullets. Physics and fictional interpretation are visually distinct. Keep the panel independently scrollable and all exit controls visible. The surface journey/log sidebar occupies the space below the code entrance; it shows actual progress and the newest archived record.
